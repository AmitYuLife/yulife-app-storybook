# YuLife Design System

### Component library + Storybook (single source of truth)

A living component library for the YuLife mobile app. Design-system components render as web React in the browser; app screens use react-native-web.

Canonical components and page templates are merged from the Journey design system (`~/Projects/design-system`). See `guidelines/merge-manifest.json` for the curated replacement list.
