# yulife-app-storybook

### YuLife Design System — Storybook workspace

This repository is a **standalone Storybook project** for documenting the YuLife component library, design tokens, page templates, and app screen compositions.

It is **not** the production mobile app repo (`yulife-rn-client`). That codebase ships the iOS and Android app; this workspace exists to browse, validate, and document UI in the browser.

  <strong style={{ color: "#111827" }}>What lives here</strong>
  <ul style={{ margin: "8px 0 0", paddingLeft: 20 }}>
    <li><code>@yulife-private/design-system</code> — web React components and tokens in <code>packages/yulife-design-system</code></li>
    <li><strong>Foundations, Templates, Components</strong> — design-system stories rendered as web React</li>
    <li><strong>Screens</strong> — app screen stories rendered via react-native-web for reference and LLM docs</li>
    <li><strong>Guidelines</strong> — LLM-oriented reference docs in <code>packages/yulife-design-system/guidelines/</code></li>
  </ul>
</div>

**Run locally:** <code>pnpm start:storybook:web</code> → http://localhost:6006

Canonical components and page templates are merged from the Journey design system (<code>~/Projects/design-system</code>). See <code>guidelines/merge-manifest.json</code> for the curated replacement list.
